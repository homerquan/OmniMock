# Samples

`commerce/` is a self-contained project containing representative input data
for the supported contract and fixture formats in the foundation: OpenAPI,
AsyncAPI, MCP, JSON Schema, GraphQL SDL, protobuf, SQL DDL, JSON, CSV, and
newline-delimited JSON. The same scenario state is projected to HTTP, SSE,
filesystem, and MCP-shaped endpoints.

`mirror_neuron/` is a self-contained, manifest-driven mock of the complete
Mirror Neuron runtime HTTP and WebSocket route surface plus the `mn` CLI
commands used for isolated OtterDesk desktop development.
